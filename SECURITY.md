# Seguridad

NVMeForge borra discos completos, así que un fallo de seguridad puede costar datos. Si encuentras uno (por ejemplo, una forma de que una página web o otro programa ordene una clonación, o de que se borre un disco distinto del confirmado), **no abras un issue público**.

Repórtalo en privado con **Security → Report a vulnerability** en este repositorio de GitHub. Incluye la versión (`NVMeForge.exe --version`), los pasos para reproducirlo y, si puedes, el registro de `%TEMP%\NVMeForge\logs`.

Las correcciones se publican como versión nueva y se documentan en [ERROR_CATALOG.md](ERROR_CATALOG.md) con su código `NVF-Exxx`.

---

To report a security issue privately, use **Security → Report a vulnerability** on this GitHub repository. Please do not open a public issue.
